Step 1: Create a GitHub repository
Open GitHub.
Repository name: html-css-assignments
Select Public.
Leave the README, .gitignore, and license options unchecked.
Click Create repository.
Step 2: Push your assignment to GitHub

Open your VS Code terminal inside your html-css-assignments folder and run:

GitHub Push Commands
git remote add origin https://github.com/Shreyasharma-ai/html-css-assignments.git
git branch -M main
git push -u origin main

Important: Run these commands after creating your repository and completing your commits. If origin is already configured, don't run the first command again.

Step 3: Verify your repository

Open your repository:

Shreyasharma-ai/html-css-assignments

Check that:

Your assignment files are visible.
Your README.md is present.
Your commit history shows at least three meaningful commits.
Step 4: Optional, host your website using GitHub Pages
Open your repository on GitHub.
Go to Settings → Pages.
Under Build and deployment, select Deploy from a branch.
Choose branch main and folder / (root).
Click Save.

Your website URL will be:

https://Shreyasharma-ai.github.io/html-css-assignments/

This works if your repository contains a suitable index.html file in its root directory.
